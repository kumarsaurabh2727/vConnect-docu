# vConnect Core Functionalities
vConnect provides the following main features:
* **Creation and orchestration of multiple API(s):**
  * Processes multiple APIs sequentially  or parallel

* **Tracing and monitoring of API(s):**
  * Offers intuitive dashboard (log stash viewer) to monitor the performance of APIs such as execution time, timeouts, average latency, and others.
  * Stores the API(s) response on server and executes API tracing rules to process request after a period of disconnection. 
  * Allows configuring alerts, API execution timeouts.

* **Managing API(s) and other features:**
  * Allows multiple API (s) to perform function in parallel across different environments.
  * API Response can be cached for a configured timeframe 
  * Provides asynchronous API processing mechanism to store the response of API in the database if it is not required by requester

* **UI enabled Dynamic Environment Management**
  * Efficiently creates required number of environments (if physical machines are available) 
  * Provides only IP addresses, and port numbers for configuration requirements.
  * Configures dedicated variables for specific environment
