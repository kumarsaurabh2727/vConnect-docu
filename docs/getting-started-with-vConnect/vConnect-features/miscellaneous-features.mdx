# Miscellaneous Features
The vConnect portal also provides other features as follows:
* **Device/App/User Management:**
  * Supports all types of devices.
  * Captures device related details such as EMEI number and login details.
  * Sends flag to the mobile app for version update.
  * Blocks users, clears app data, or destroys app.

* **Enabler:**
  * Manages push notifications in both android and apple devices. 
  * Manages media and documents that are transferred between client application environment and server.
  * Tracks Geo-location of requester.
  * Provides Sync Engine (store and forward) that smartly works with app in offline mode.

* **Debugging and Logs Management:**
  * Manages communication logs and histories of all transactions that are processed between client environment and server. 
  * Audit logs can be managed as ON/OFF at API level or App Level.
  * Debugs micro-services with detailed server level logs of input and output operations.
