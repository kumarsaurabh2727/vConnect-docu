# vConnect Connector
Primarily, vConnect connectors are used to configure several API interfaces, databases, and AWS lambda services. It helps design SOAP/REST API(s) to consume databases, web services, lambda services, and establishes the connection with third party API. These connections can be configured by providing host, port number, and details of database names and schemas.

The vConnect connectors can be used as follows:
* Connect RESTful API(s) to databases 
* Connects help execute drivers such as functions and procedures in the database
* UI-enabled configuration of parameters can be either passed in or returned from the function
* By using lambda service, the connector can convert Python, Java class or function, or java script files into API.
