# Accessing Project Management Workbench
After you successfully access the Vahana platform, you need to access the project management workbench. It allows you to create an app. When you create an app on the Vahana platform, it automatically creates an app ID and assigns it to the newly created app.

Later, when you access the Vahana platform or other application hosted on the Vahana platform, it authorizes your login request by using the org ID and app ID.

To create an app:
1. On the Vahana portal's home page, click the **New Application** link to display the **Create an App** page.
2. On the **Create an App** page, enter values in respective boxes as follows:

|**Boxes**|**Description**|
|------|-----|
|**App Name**|In this box, enter the app name.| 
|**Add Description**|In this box, enter the description of your app or a reason to create the app.|

3. After you enter app’s name and description, click the **Submit** link to successfully create the app.
