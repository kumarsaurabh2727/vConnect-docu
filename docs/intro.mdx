# An Introduction to vConnect
vConnect is a web-based portal that is deployed on the Vahana platform. On Vahana platform, it serves as robust, scalable, and intelligent middleware that allows multiple mobile app, web applications and other enterprise level systems and entities to communicate over single platform. vConnect smartly provides a service passage to integrate front-end application and mobile apps with the back-end databases, external databases via API calls. vConnect workflow is based on micro-services architecture that allows you to orchestrate multiple APIs call to backend. 

Conclusively, vConnect serves as an aggregator platform that hosts multiple native and third party API(s), databases, and lambda services. It works as a resident API manager. Major functional advantages of vConnect are listed as below:
* To fulfill the transaction, it smartly returns single micro-service based response, which optimizes data traffic over the network backbone and increases overall throughput
* It can be efficiently used beyond the traditional concepts of ESB services and API management
* It allows monitoring, reporting, and debugging that are mandatory activities to maintain API’s performance
* It helps you monetize API in better ways
* It helps you enhance API’s performance to provide improved service offerings
* On vConnect platform, you can incorporate required changes without affecting user-experience and downtime
* To maximally use of API(s), it provides constant monitoring and other health metrics through single web based dashboard
* It periodically captures the audit logs that can be vitally used to prepare bank related reports and logs
* Being built on ELK stack, it provides real-time server and machine-monitoring experience, in addition to handy features, interactive data visualization through single web based dashboard 

By using high-level RSA and AES encryption mechanism, vConnect manages the flow of data between bank’s core services and third party systems, which allows maintaining the level of abstraction between these two entities. When a user performs the action on the mobile app or web application, a user-request is generated. The request invokes the corresponding API of the vConnect platform. After the respective API is invoked, it accesses the database repository and returns response.
